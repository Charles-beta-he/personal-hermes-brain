## 二、健康度函数 V(x) — Agent 的李雅普诺夫函数

```
V = 0.30 × 任务成功率
  + 0.25 × 用户满意度（纠正频率的倒数）
  + 0.20 × skill 覆盖率（任务类型 / 有对应 skill 的类型）
  + 0.15 × 构建通过率（test + build）
  + 0.10 × 迭代效率（1 / 平均轮次）

V̇ = V(t) - V(t-1)  // 每 session 计算一次
```

**进化判定：**
- V̇ > 0.05：显著进化 ✓
- -0.05 ≤ V̇ ≤ 0.05：停滞 ⚠️（需引入新刺激）
- V̇ < -0.05：退化 ✗（立即触发复盘）

## 四、控制论改造后的 Agent 工作流

### 标准任务闭环（带控制论增强）

```
[0] 需求接收
    └── requirement-clarification skill（明确目标函数 J）
    └── 输出：AC + 性能指标权重

[1] 战略设计 (P10)
    └── 读取 reference-model.md（参考模型）
    └── 检查 V(t-1)，如 V̇ < 0 触发战略调整
    └── 输出：p10-strategy.md

[2] 任务拆解 (P9)
    └── 分解为原子任务（大系统分解）
    └── 定义每个子任务的信息模式（最小必要上下文）
    └── 输出：p9-tasks.md + todo list

[3] 编码实现 (P8/P7)
    └── 按 TDD 执行（状态反馈控制）
    └── 每步验证（高频采样）
    └── 偏差检测：实际 vs 参考模型

[4] 代码审查
    └── 独立 reviewer（冗余设计）
    └── 安全扫描 + 基线测试（故障检测）

[5] 验证测试
    └── UIMax audit + browser harness（多维度观测）
    └── 计算本轮 V 贡献值

[6] 构建部署
    └── semantic-release 自动版本（稳定释放）

[7] 上线验证
    └── 生产环境健康检查（观测器验证）
    └── 计算 V(t)，更新 V̇

[8] 事故/复盘
    └── FDIR：检测→隔离→恢复→复盘
    └── 如 V̇ < -0.05，触发根因分析

[9] 持续优化
    └── loop 执行，每轮计算 V
    └── 极限环检测：同问题重复预警
    └── skill 评分更新（强化学习）
```

## 七、风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| V 计算过度复杂 | 增加认知负担 | V 自动计算，Agent 只读结果 |
| 过度自适应导致震荡 | 策略频繁切换 | 设置最小切换周期（类似采样定理） |
| Skill 膨胀 | 覆盖率高但维护难 | AIC 准则惩罚复杂 skill |
| 遗忘因子不当 | 核心能力丢失 | λ 分级：原则 λ=1，技术 λ=0.95 |
| 多 Agent 冲突 | 分散控制失效 | 严格接口契约 + 统一验收标准 |
