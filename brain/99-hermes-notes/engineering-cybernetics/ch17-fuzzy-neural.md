# 第十七章 模糊控制与神经网络

## 核心观点
模糊控制处理人类语言中的不精确性；神经网络处理复杂非线性映射。
两者结合 = 模糊神经网络 = 可解释的适应性系统。

## 关键概念
- **模糊集合**: 隶属度函数代替二值隶属
- **模糊推理**: IF 温度高 THEN 风扇快（语言规则）
- **神经模糊系统**: 用 NN 学习模糊规则和调整隶属度
- **深度强化学习**: 神经网络 + 奖励信号 → 策略优化

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 隶属度 | Agent 对需求理解的置信度（0-1） |
| 模糊规则 | "如果用户说'优化'，那么优先性能而非功能" |
| 神经模糊 | LLM 作为可学习的推理引擎 + skill 作为结构化规则 |
| 强化学习 | 用户反馈作为 reward，优化 Agent 策略 |
| 探索 vs 利用 | 尝试新方案 vs 使用已验证的方案 |

## 进化启示
**模糊性处理**
用户请求天然模糊：
- "把这个页面做好看点" → 没有明确验收标准
- 模糊控制思维：定义"好看"的隶属度函数（间距合适、对比度够、动效流畅）
- 用模糊规则将定性需求转化为定量行动

**强化学习框架**
将 Agent 的每次交互建模为 MDP：
- 状态 s：当前上下文 + 历史记忆
- 动作 a：选择哪个 skill / 生成什么响应
- 奖励 r：用户满意度 + 任务完成度 + 效率
- 策略 π：Agent 的行为模式

目标：π* = argmax E[Σγᵗrₜ]

**探索-利用权衡**
- 利用（Exploitation）：使用已知最优 skill → 稳定产出
- 探索（Exploration）：尝试新 skill / 新参数 → 可能发现更好方案
- ε-贪心：以 ε 概率探索，1-ε 概率利用
- Agent 应用：大部分任务用成熟 skill，偶尔尝试新思路
