# 第二章 线性系统与传递函数

## 核心观点
用微分方程描述系统动态，用传递函数 G(s) = Y(s)/U(s) 刻画输入-输出关系。
线性系统满足叠加原理：多个输入的响应等于各自响应之和。

## 关键概念
- **状态空间表示**: ẋ = Ax + Bu, y = Cx + Du
- **传递函数**: 复频域下的输入输出比，极点决定系统固有特性
- **脉冲响应**: 时域完全刻画系统行为
- **叠加原理**: 系统对多个输入的总响应等于对单个输入响应之和

## 数学要点
- 拉普拉斯变换将微分方程转化为代数方程
- 特征方程 det(sI - A) = 0 的根决定系统模态
- 零状态响应 + 零输入响应 = 完全响应

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 输入 u(t) | 用户请求 / 外部事件 |
| 输出 y(t) | Agent 的响应 / 交付物 |
| 状态 x(t) | Agent 的上下文记忆 + session 状态 |
| A 矩阵 | 系统内部演化规律（skill 更新、记忆固化） |
| B 矩阵 | 外部输入对状态的影响权重 |
| 传递函数 | Agent 从请求到响应的"性格"特征 |
| 叠加原理 | 多任务并发处理能力 |

## 进化启示
Agent 的"性格"（从输入到输出的映射规律）可以通过传递函数思想建模。
优化 Agent = 调整其"传递函数"，使其对各类输入产生期望输出。

**实践：将 Agent 工作流抽象为状态机**
- 状态变量：当前任务阶段、已收集信息、已知风险
- 输入矩阵 B：用户指令如何改变任务状态
- 输出矩阵 C：当前状态下 Agent 如何表达/交付
