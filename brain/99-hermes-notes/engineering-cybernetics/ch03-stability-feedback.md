# 第三章 反馈控制系统的稳定性分析

## 核心观点
反馈是把双刃剑：正反馈放大偏差导致失稳，负反馈抑制偏差实现稳定。
稳定性是控制系统的第一要求——不稳定的系统再精确也毫无意义。

## 关键概念
- **负反馈**: 输出偏差反向作用于输入，抑制扰动
- **劳斯判据**: 不解方程判断特征根是否全在左半平面
- **乃奎斯特判据**: 通过开环频率特性判断闭环稳定性
- **稳定裕度**: 增益裕度 + 相位裕度，量化"离不稳定有多远"

## 数学要点
- 闭环传递函数 Φ(s) = G(s)/(1 + G(s)H(s))
- 特征方程 1 + G(s)H(s) = 0 的根决定稳定性
- 乃奎斯特曲线包围 (-1, j0) 点的圈数 = 右半平面闭环极点数

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 负反馈 | 用户纠正 → 修正行为 |
| 正反馈 | "越错越离谱"的级联错误（需避免） |
| 劳斯判据 | 交付前自检清单（不执行就判定不合格） |
| 乃奎斯特判据 | 开环测试：单个工具是否正常，再判断组合风险 |
| 稳定裕度 | Agent 在面对模糊/错误输入时的容错能力 |
| 扰动抑制 | 应对环境变化（API变更、依赖升级）的鲁棒性 |

## 进化启示
**稳定优先于最优。** Agent 工作流必须内置负反馈机制：
1. 每轮执行后验证（负反馈）
2. 用户纠正后立即调整（高增益反馈）
3. 避免"自我确认偏差"正反馈（不断用错误前提推出更错结论）

**乃奎斯特思想在 Agent 中**
- 开环测试 = 单个 skill 独立验证
- 闭环测试 = 完整工作流端到端验证
- 开环正常 ≠ 闭环稳定（ skill 单独好 ≠ 组合工作流不出问题）

**稳定裕度 = 鲁棒性**
- 增益裕度：Agent 在"过度自信"时仍不崩溃
- 相位裕度：Agent 在"延迟反馈"时仍保持稳定
