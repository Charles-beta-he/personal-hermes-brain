# 第七章 非线性系统分析

## 核心观点
真实系统几乎都是非线性的。线性化只在平衡点附近有效，
远离平衡点时必须直面非线性——相平面、描述函数、波波夫判据。

## 关键概念
- **相平面法**: 用状态变量的相轨迹定性分析系统行为
- **描述函数法**: 将非线性环节等效为变增益放大器
- **极限环**: 自激振荡的数学表现（稳定的或不稳定的）
- **分叉 (Bifurcation)**: 参数微小变化导致定性行为突变

## 数学要点
- 非线性微分方程一般无解析解，依赖数值和定性方法
- 李纳方程 ẍ + f(x)ẋ + g(x) = 0 的相图分析
- 描述函数 N(A) = (输出基波)/(输入正弦)

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 相平面 | Agent 的"状态-状态导数"空间（能力 vs 改进速度） |
| 极限环 | Agent 陷入"改A坏B→改B坏A"的无限循环 |
| 描述函数 | 用等效增益近似复杂环节（如用户反馈的非线性响应） |
| 分叉 | 微小的 skill 调整导致工作流行为质变（如好/坏突变） |
| 平衡点 | Agent 的"稳态性能"——无新任务时的默认响应质量 |

## 进化启示
**非线性 = 真实世界的常态**
Agent 工作流中的非线性来源：
1. **阈值效应**: 代码审查强度超过某阈值后，反而降低效率
2. **饱和**: Agent 同时处理任务数过多时，边际产出递减
3. **死区**: 微小反馈被忽略，积累到阈值后突然爆发
4. **滞环**: 用户纠正后，Agent 不是立即改，而是需要多次强化

**极限环的识别与打破**
如果 Agent 反复陷入同一类问题（如"修bug→引入新bug→修新bug→旧bug复发"），
这就是极限环振荡。打破方法：
1. 改变反馈增益（减少每轮改动幅度）
2. 引入非线性补偿（增加前置验证环节）
3. 切换控制策略（从P8执行切换到P7方案设计）

**分叉预警**
当某个参数（如 model temperature、context window）接近临界值时，
Agent 行为可能发生质变。需要监控"分叉指标"：
- 任务成功率突变
- 平均轮次突然增加
- 用户纠正频率陡升
