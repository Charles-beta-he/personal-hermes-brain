# 第五章 采样（离散）控制系统

## 核心观点
数字控制系统不是连续的，而是离散时间系统。
采样间隔的选择至关重要：太疏丢失信息，太密浪费资源。

## 关键概念
- **Z变换**: 离散系统的"拉普拉斯变换"
- **采样定理 (香农)**: 采样频率 > 2×信号最高频率
- **保持器**: 零阶保持 (ZOH) 将离散信号恢复为连续信号
- **混叠**: 采样不足导致高频信号伪装成低频

## 数学要点
- G(z) = Z{G(s)/s} 含零阶保持器的离散化
- 稳定性判据：特征根在 Z 平面单位圆内
- w 变换将单位圆内映射到左半平面，可用连续系统方法分析

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 采样周期 T | Agent 的执行轮次间隔 / 自检频率 |
| 香农定理 | 用户反馈频率决定 Agent 调整频率上限 |
| 零阶保持 | 上轮决策在本轮持续生效（直到新反馈到达） |
| 混叠 | 低频自检无法发现高频问题（如偶发 bug） |
| Z 平面单位圆 | 迭代的收敛条件：每次调整必须"衰减" |

## 进化启示
**采样频率设计**
- 高频采样（每步验证）：资源消耗大，适合关键路径
- 低频采样（每轮结束验证）：效率高，但问题发现晚
- 自适应采样：关键阶段高频，常规阶段低频

**混叠与偶发问题**
如果 Agent 只在固定时刻检查状态，可能错过偶发错误。
解决方案：
1. 随机采样（在 loop 中随机插入验证点）
2. 事件驱动采样（仅在状态变化时检查）
3. 累积采样（记录日志，事后分析）

**离散稳定性**
Agent 的迭代改进必须满足"衰减条件"：
每次修改的幅度应该逐渐减小（收敛），而不是振荡发散。
如果 loop 每轮改动越来越大，说明系统不稳定。
