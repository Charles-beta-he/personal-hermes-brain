# 第一章 引言 — 控制论的诞生与工程意义

## 核心观点
钱学森将控制论从维纳的哲学层面转化为可工程的数学框架。
控制论研究的是"系统在给定目标下如何行动"，而非具体物理实现。

## 关键概念
- **目的性 (Teleology)**: 系统不是被动响应，而是主动趋向目标
- **信息反馈**: 控制的核心机制是信息的获取、处理与反馈
- **广义系统**: 控制系统可以是机械、电气、生物、社会、智能体

## 原文精髓
> "工程控制论研究的是控制系统的共同规律，而不涉及具体实现。"

这意味着方法论可以跨域迁移：导弹导航的稳定性理论同样适用于 Agent 决策闭环。

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 系统 | AI Agent 本身 |
| 目标函数 | 任务完成质量 + 用户满意度 |
| 控制器 | P10/P9 战略层 + Prompt 工程 |
| 执行器 | P8/P7 执行层（工具调用） |
| 传感器 | browser/console/search 等反馈通道 |
| 反馈回路 | 验证 → 评估 → 修正 的闭环 |

## 进化启示
Agent 不是一次性写好的程序，而是**持续接收反馈、调整行为的动态系统**。
