# 第八章 稳定性理论 — 李雅普诺夫直接法

## 核心观点
不必解微分方程，通过构造"能量函数"直接判断稳定性。
这是现代控制论最重要的理论工具，将定性判断转化为构造性问题。

## 关键概念
- **李雅普诺夫稳定性**: 扰动后系统保持在平衡点附近
- **渐近稳定性**: 扰动后系统不仅保持，还回到平衡点
- **李雅普诺夫函数 V(x)**: 正定、沿轨迹递减的"能量"函数
- ** Lasalle 不变集原理**: 处理 V̇ 半负定的情况

## 数学要点
- 若 ∃V(x)>0 (x≠0), V(0)=0, 且 V̇(x)≤0 → 稳定
- 若 V̇(x)<0 (x≠0) → 渐近稳定
- 若 V(x)→∞ 当 ||x||→∞ → 全局渐近稳定
- 不稳定性：若 V̇>0 在某区域

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 平衡点 x=0 | Agent 的"理想状态"——零错误、零反馈、自洽运行 |
| 李雅普诺夫函数 V(x) | Agent 的"健康度指标"——质量评分 + 效率评分 |
| V̇ < 0 | 健康度持续改进（每次迭代都在变好） |
| V̇ = 0 | 系统停滞——Agent 在原地打转 |
| V̇ > 0 | 系统退化——越改越差 |
| 全局渐近稳定 | 无论初始状态多差，Agent 最终都能收敛到高质量 |

## 进化启示
**构造 Agent 的李雅普诺夫函数**
定义 V = α·任务成功率 + β·用户满意度 - γ·平均轮次 - δ·资源消耗

V̇ > 0 的条件：
- 成功率提升（正贡献）
- 用户纠正减少（正贡献）
- 轮次减少（正贡献）

**渐近稳定 = 持续进化**
Agent 系统必须满足：每次 session 结束后，长期状态比开始前更好。
这要求：
1. memory 正确固化（不遗忘有用的）
2. skill 有效更新（不破坏已有的）
3. evolution 基线只升不降

**不稳定检测**
如果出现以下情况，系统不稳定：
- 同类型错误重复出现（V 不下降）
- 新 skill 引入后旧功能损坏（V 上升）
- 用户反馈从"好用"变成"越来越怪"（V 上升）

**Lasalle 原理**
即使某些时刻 V̇ = 0（如暂时没有任务），只要不变集只包含平衡点，
系统最终仍会收敛。对应：Agent 在空闲期保持状态不退化即可。
