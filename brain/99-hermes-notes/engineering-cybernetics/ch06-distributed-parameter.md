# 第六章 分布参数控制系统

## 核心观点
有些系统的状态不仅随时间变化，还随空间分布——用偏微分方程描述。
工程实例：热传导、弹性振动、流体流动、大规模并行计算。

## 关键概念
- **偏微分方程 (PDE)**: 状态是时空函数 u(x,t)
- **模态分析**: 将无限维系统投影到有限个特征模态
- **边界控制**: 通过边界条件而非全域施加控制
- **集中化近似**: 用有限个集中参数近似分布参数

## 数学要点
- 波动方程、热传导方程的标准形式
- 分离变量法得到特征函数展开
- Galerkin 方法将 PDE 转化为 ODE 组

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 分布参数 | Agent 的"认知场"——知识在空间（领域）上分布 |
| 模态分析 | 将复杂 Agent 分解为独立 skill（特征模态） |
| 边界控制 | 通过接口/契约控制子系统，不干涉内部 |
| 集中化近似 | 将复杂问题拆解为有限个子任务 |

## 进化启示
**Agent 是分布参数系统**
Agent 的"状态"不是几个标量，而是分布在多个维度上的：
- 时间维度：session 历史、长期记忆
- 领域维度：前端、后端、DevOps、设计
- 质量维度：正确性、性能、安全、体验

不能用单维指标评估 Agent，需要多维"场"的视角。

**模态分析 = Skill 解耦**
将 Agent 能力分解为正交 skill：
- 每个 skill 对应一个"特征模态"
- skill 之间低耦合（正交性）
- 新 skill 的引入不破坏已有 skill（模态叠加）

**边界控制 = 接口约束**
不 micromanage P8 的内部实现，只通过 Task Prompt（边界条件）约束输入输出。
