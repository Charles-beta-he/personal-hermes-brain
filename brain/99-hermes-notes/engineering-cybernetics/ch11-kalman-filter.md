# 第十一章 状态估计与滤波 — 卡尔曼滤波

## 核心观点
状态往往不能直接测量，需要从噪声污染的观测中最优估计。
卡尔曼滤波 = 预测 + 修正，最小均方误差的最优递推估计。

## 关键概念
- **状态估计**: 从输出 y 推断状态 x̂
- **预测步**: 基于模型推演下一时刻状态
- **修正步**: 用新观测更新预测，权重由协方差决定
- **卡尔曼增益 K**: 信任预测 vs 信任观测的权衡

## 数学要点
- 预测：x̂ₖ|ₖ₋₁ = Fx̂ₖ₋₁ + Buₖ₋₁, Pₖ|ₖ₋₁ = FPₖ₋₁Fᵀ + Q
- 修正：K = Pₖ|ₖ₋₁Hᵀ(HPₖ|ₖ₋₁Hᵀ + R)⁻¹
- 更新：x̂ₖ = x̂ₖ|ₖ₋₁ + K(yₖ - Hx̂ₖ|ₖ₋₁)

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 真实状态 x | Agent 的真实能力/知识状态（不可直接观测） |
| 观测 y | 用户反馈、测试结果、代码审查意见 |
| 观测噪声 R | 反馈的不确定性（用户可能错、测试可能漏） |
| 过程噪声 Q | Agent 能力的自然漂移（记忆衰减、环境变化） |
| 卡尔曼增益 K | 对新反馈的信任程度（高K = 快速响应，低K = 谨慎） |
| 估计误差 P | Agent 对自身能力评估的不确定性 |

## 进化启示
**Agent 的自认知是估计，不是事实**
Agent 永远无法直接知道自己"真正"的能力，只能通过反馈推断。
卡尔曼滤波思想：
1. 预测：基于历史表现，估计当前能力
2. 观测：获取新的用户反馈/测试结果
3. 融合：按可信度加权，更新能力估计

**卡尔曼增益的调节**
- K 大（信任观测）：新反馈权重高 → 快速适应但易受噪声影响
- K 小（信任预测）：历史估计权重高 → 稳定但适应慢
- 最优 K：随估计精度自动调整（P 小 → K 小，P 大 → K 大）

Agent 实现：
- 新任务/新项目 → P 大（不确定）→ K 大（多听反馈）
- 熟悉领域 → P 小（自信）→ K 小（稳定执行）
- 连续出错 → P 重新增大 → K 增大（重新学习）

**扩展卡尔曼滤波 (EKF)**
当系统非线性时，在局部线性化后应用卡尔曼滤波。
对应 Agent：复杂任务分段线性近似，每段独立估计和调整。
