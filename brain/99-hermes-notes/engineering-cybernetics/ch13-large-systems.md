# 第十三章 大系统理论

## 核心观点
当系统规模极大（子系统数量多、层次深、耦合复杂），集中控制不可行。
大系统理论 = 分解 + 协调，用"分而治之"实现可控性。

## 关键概念
- **分解**: 将大系统拆分为相对独立的子系统
- **协调**: 通过目标协调、模型协调、预测协调统一行动
- **递阶结构**: 多层控制，上层协调下层
- **分散控制**: 各子系统独立决策，只交换必要信息
- **稀疏性**: 大系统的关联矩阵通常是稀疏的

## 数学要点
- 互联系统：ẋᵢ = Aᵢxᵢ + Bᵢuᵢ + ΣⱼAᵢⱼxⱼ
- 目标协调：拉格朗日松弛引入协调向量 λ
- 模型协调：固定关联变量，子系统独立优化

## 进化启示
**分解原则**
复杂任务必须分解，否则：
- context window 溢出
- 单点失败导致全系统崩溃
- 无法并行执行

分解标准：
1. 功能内聚（每个子系统负责单一职责）
2. 接口最小化（子系统间交换最少信息）
3. 故障隔离（一个子系统失败不影响其他）

**协调机制**
三种协调方式在 Agent 中的体现：
1. 目标协调：所有 sub-agent 共享统一的验收标准
2. 模型协调：共享项目上下文和约束条件
3. 预测协调：基于对其他 agent 输出的预期来调整自身计划

**递阶 vs 分散的权衡**
- 递阶：P10 统一协调，适合战略一致性强的大型项目
- 分散：sub-agent 自主决策，适合需要快速响应的紧急任务
- 混合：战略层递阶，执行层分散
