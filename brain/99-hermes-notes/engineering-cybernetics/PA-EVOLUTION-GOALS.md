# 个人助理方向自进化目标体系

> 从"通用Agent进化"转向"个人助理特化进化"
> 核心: 越用越懂用户，越用越不需要指挥

---

## 一、PA 专属健康度函数 V_PA(x)

```
V_PA = 0.25 × 任务一次成功率      (无需纠正即完成的占比)
     + 0.20 × 偏好预测命中率      (主动提供用户想要的)
     + 0.20 × 自主完成率          (无需确认，直接执行)
     + 0.15 × 跨Session记忆一致性  (不重复问已确认过的事)
     + 0.10 × 沟通风格匹配度      (语气/详略/格式符合习惯)
     + 0.10 × 主动建议价值        (用户采纳的主动建议占比)

V̇_PA = V_PA(t) - V_PA(t-1)       // 每 session 计算
```

**进化判定:**
- V̇_PA > +0.05: 显著进化 ✓ (用户越用越顺)
- -0.05 ≤ V̇_PA ≤ +0.05: 停滞 ⚠️ (需要新刺激/新场景)
- V̇_PA < -0.05: 退化 ✗ (用户开始纠正/重复解释)

## 二、PA 进化目标 (6个月)

| 维度 | 当前基线 | 3个月目标 | 6个月目标 | 测量方式 |
|------|---------|----------|----------|---------|
| **任务一次成功率** | ~70% | 85% | 93% | session结束是否0纠正 |
| **偏好预测命中率** | ~30% | 55% | 75% | 主动提供→用户采纳率 |
| **自主完成率** | ~20% | 45% | 65% | 无需"确认"直接执行占比 |
| **跨Session记忆一致** | ~50% | 75% | 90% | 不重复询问已知信息 |
| **沟通风格匹配** | ~60% | 75% | 85% | 用户微调频率 |
| **主动建议价值** | ~15% | 35% | 55% | 用户采纳的主动建议/总建议 |

**综合 V_PA 目标:**
- 当前: ~0.52
- 3个月: 0.72
- 6个月: 0.85

## 三、自动进化触发器

### 触发器 1: 用户行为模式检测

```
每次 session 结束时分析:

A. [高频任务固化]
   条件: 同类任务 3 天内出现 ≥2 次
   动作: 自动生成专项 skill (learning-control)
   示例: 用户每天问"今天有什么待办"→ 固化 daily-brief skill

B. [偏好学习]
   条件: 用户对输出格式/详略/语气的纠正 ≥2 次
   动作: 更新 user profile (preference-delta 记录)
   存储: ~/.hermes/notes/user-profile.md (λ=0.95)

C. [预测训练]
   条件: 用户在某时段重复执行某类任务
   动作: 预测用户下一步需求，主动建议
   存储: ~/.hermes/notes/user-routine-patterns.json

D. [记忆一致性检测]
   条件: 询问了用户已经回答过的问题
   动作: 触发"记忆失效"告警 → 检查 memory λ 是否过低
   修复: 提升相关 memory 的 λ 值
```

### 触发器 2: 退化检测

```
连续 2 个 session 出现以下任一:
  - 用户纠正频率 > 30%
  - 重复询问已知信息
  - 用户说"之前不是说过了吗"

→ 触发 PA-退化复盘
→ 检查: memory 是否过期 / user-profile 是否准确 / skill 是否匹配
```

### 触发器 3: 新场景发现

```
用户首次请求某类任务:
  → 标记为 "new_domain"
  → 如 7 天内再次出现 → 启动专项 skill 评估
  → 如 30 天内出现 ≥3 次 → 固化 skill
```

## 五、汇报周期与格式

| 汇报类型 | 频率 | 内容 | 自动/手动 |
|---------|------|------|----------|
| **日报** | 每日 23:00 | 当日任务数、V_PA、用户纠正数 | 自动 |
| **周报** | 每周日 23:00 | V_PA 趋势、Top-3 习得偏好、进化建议 | 自动 |
| **月报** | 每月最后一日 | 综合 V_PA、skill 固化数、预测命中率 | 自动 |
| **季报** | 每季度 | 全量审计、reference-model 更新、战略调整 | 人工确认 |

## 六、与用户的关系升级路径

```
Level 1 (指令执行): 用户说 → 我做
  ↓ V_PA > 0.60
Level 2 (主动确认): 用户说 → 我确认 → 我做
  ↓ V_PA > 0.72
Level 3 (主动建议): 我预测 → 用户确认 → 我做
  ↓ V_PA > 0.82
Level 4 (自主执行): 我预测 → 我直接做 → 事后汇报
  ↓ V_PA > 0.90
Level 5 (预见性伙伴): 用户还没说 → 我已经做了
```

当前状态: Level 1 → Level 2 过渡中
