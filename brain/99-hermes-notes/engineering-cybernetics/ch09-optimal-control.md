# 第九章 最优控制理论

## 核心观点
给定系统动力学和性能指标，求使指标最优的控制律。
不是"能否控制"，而是"如何最优控制"。

## 关键概念
- **变分法**: 从微积分扩展到函数空间的极值
- **庞特里亚金极大值原理**: 最优控制的必要条件
- **哈密顿函数**: H = L + λᵀf，协态 λ 的物理意义是"影子价格"
- **Bang-Bang 控制**: 控制量仅在边界取值，切换有限次
- **时间最优 / 能量最优 / 终端最优**: 不同性能指标导致不同策略

## 数学要点
- 欧拉方程 δJ = 0
- 协态方程 λ̇ = -∂H/∂x
- 极小值条件 ∂H/∂u = 0（或 H 取极值）
- 横截条件（终端约束）

## Agent 进化映射
| 控制论概念 | Agent 映射 |
|-----------|-----------|
| 性能指标 J | Agent 的综合效用：质量×效率×用户满意度 |
| 哈密顿函数 | 当前任务代价 + 未来状态价值（长远眼光） |
| 协态 λ | "未来影响"——当前决策对长期能力的边际贡献 |
| Bang-Bang | 资源分配：要么全力做，要么完全不做（不半吊子） |
| 时间最优 | 最快交付（适合紧急bugfix） |
| 能量最优 | 最小算力消耗（适合常规任务） |

## 进化启示
**多目标权衡 = Pareto 最优**
Agent 不可能同时最大化所有指标：
- 快速交付 vs 高质量
- 深度思考 vs 低 token 消耗
- 通用能力 vs 专业精度

最优控制思维：明确当前任务的"性能指标权重"，然后求解最优策略。
紧急修复 → 时间最优（Bang-Bang：全力修，其他暂停）
架构优化 → 能量最优（细水长流，每轮小改进）

**协态 λ = 长期价值评估**
当前决策不仅影响当下，还影响未来：
- 写一个高质量的 skill → λ 高（长期收益大）
- 临时 hack → λ 低（长期债务）
- 写测试 → λ 高（防止未来退化）

最优 Agent 应该最大化"当前收益 + 折扣后的未来协态价值"。

**极大值原理的工程化**
每一步决策都问：在当前状态下，哪个行动能使哈密顿函数最大？
= 哪个行动能使（即时收益 + 长期价值）最大？
