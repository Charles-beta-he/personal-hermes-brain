# Evidence boundary: lossy summary cannot replace original evidence

## Principle

A lossy summary is a routing artifact, not a fact source。

MemPalace-style Closet / AAAK / compressed symbolic summary can help recall, but it cannot reconstruct the original evidence. Therefore every derived summary must keep a source pointer to original evidence。

## Rule

- Summary → useful for navigation。
- original evidence → source of truth。
- source pointer → required for promotion into durable memory。

## Local-brain mapping

- Drawer: `09-引用原文`, raw logs, original notes。
- Closet: MOCs, indexes, dashboards, derived cards。

If a claim matters, verify it against original evidence before acting。
