# Main hierarchy as control-plane

## Principle

Obsidian 主层级应该是 control-plane，而不是把所有理论细分摊平成顶层目录。

## Rule

顶层目录只承载最稳定的操作平面：system/preferences、evidence/source、theory/metacognition、atoms、practice/projects、governance/reviews、dashboard、templates、agent notes。

## Evidence boundary

迁移完成不等于知识正确；它只说明导航和治理结构已通过 deterministic gates。
