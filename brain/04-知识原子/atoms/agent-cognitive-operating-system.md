# Agent Cognitive Operating System

Agent COS 是一条稳定原则：Agent 的“认知能力”必须像操作系统一样有层次、有接口、有调度、有监控、有错误恢复，而不是依赖一次性 prompt 或单个强模型。

## Stable Claim

一个完整 Agent 认知操作系统至少包含：感知、工作记忆、状态估计、决策、执行、反馈、学习、治理、资源调度、停止条件、证据边界、进化机制。

每个能力位必须有互补理论配对：控制论提供反馈骨架，但需要认知科学补工作记忆，贝叶斯补不确定性，OODA补速度，达尔文补进化，Popper补证伪，经济学补停止条件，Ostrom/Parnas补治理与边界。

## Non-negotiable Evidence Rule

模型一致不是证据；A+ 评级必须绑定本地大脑可复现证据。若多模型讨论超时或 not_certified，仍可作为 provenance，但不可替代 audit/search/selfcheck。
