# Keypoint-to-multimodel routing

## Principle

关键点是否介入多模型思考，不按“是否重要”单轴决定，而按 complexity、uncertainty、reflexivity、blast radius 四轴决定。

## Routing rule

- T0：工具可直接验证，低风险，不调用多模型。
- T1：轻量 reviewer。
- T2：多模型 seed fanout + 本地 deterministic gate。
- T3：完整 discussion/ratification；若 timeout/dissent，则记录 not_certified，不伪装认证。

## Highest-priority keypoints

- 必要多样性。
- 反馈稳定性。
- 置信度校准与证据等级。
- 双环学习。
- 技能生态治理。
- 本地大脑 source of truth / evidence boundary。
