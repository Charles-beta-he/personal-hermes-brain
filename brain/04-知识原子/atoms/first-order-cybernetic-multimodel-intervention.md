# First-order cybernetics: multi-model controls the object task

## Principle

first-order cybernetics treats the observer/controller as outside the object task。

In Hermes, multi-model thinking can intervene as a first-order controller when the target is a repo, note hierarchy, architecture decision, API integration, or external system。

## Rule

Multi-model output is hypothesis generation and risk discovery。Acceptance requires tool evidence。

## Pass gate

- object task is clearly framed。
- models produce proposals / critiques / experiments。
- deterministic evidence verifies the final claim。
- model agreement is not evidence。
