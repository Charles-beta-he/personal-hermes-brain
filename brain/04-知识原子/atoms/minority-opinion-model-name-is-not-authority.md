# Minority opinion: model name is not evidence

## Principle

model name is not evidence。

A minority opinion from a cheaper or weaker model can still identify a real blocker. A majority opinion from stronger model names can still be unsupported。

## Governance rule

- Preserve minority opinion in the issue ledger。
- Resolve by evidence quality and deterministic verification, not by model prestige。
- If a reviewer times out, fails parsing, or is unavailable, record the caveat instead of pretending consensus。
