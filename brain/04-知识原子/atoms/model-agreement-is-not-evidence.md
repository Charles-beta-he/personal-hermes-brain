# Model agreement is not evidence

Multi-model agreement is useful as review pressure, but it is not factual evidence. Factual claims still require tool outputs, source links, command results, screenshots, or other evidence bundles.

Routing rule:

- Multi-model output goes to `06-治理与评审/reviews/` as L6 review artifact.
- Evidence-backed stable claims can later be promoted to `04-知识原子/atoms/` or `05-实践与项目/projects/`.
- Unsupported claims remain review hypotheses, even if all models agree.

Current case:

The 2026-05-06 local-brain hierarchy had four-model seed fanout, but discussion/consensus timed out. It is multi-model provenance, not fully ratified certification.
