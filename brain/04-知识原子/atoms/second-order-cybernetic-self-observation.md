# Second-order cybernetics: multi-model observes the observer

## Principle

second-order cybernetics brings the observer into the system。

In Hermes, this means the agent must audit its own controller: route choice, skill loading, memory writes, evidence gate, issue ledger, timeout handling, and certification language。

## Rule

A multi-model review is incomplete if it only reviews the object task and never reviews the reviewer。

## Self-audit questions

- Did I choose the right model tier/quorum?
- Did I mistake consensus for evidence?
- Did any timeout or dissent get hidden?
- Did a memory write risk becoming ghost context?
- Are my audit rules themselves stale or circular?
