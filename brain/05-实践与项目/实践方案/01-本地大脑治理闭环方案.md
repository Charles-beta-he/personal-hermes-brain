# 本地大脑治理闭环方案

## 步骤

1. 扫描目录：空白、无 MOC、薄弱目录。
2. 写入内容：MOC、概念卡、证据边界、任务日志。
3. 验证：`brainctl sync`、`brainctl reindex`、`brainctl search`。
4. 复审：重新扫描，直到 P0/P1 gap 为空。
5. 固化：写入 `06-治理与评审/进化日志/` 和本地 git commit。
