# Project - Agent Cognitive Operating System

## North Star

Agent 认知操作系统（COS）不是再增加一堆松散理论卡，而是把 Hermes Agent 的认知能力拆成可观测、可路由、可验证、可进化的操作系统层：

1. 感知与证据采集：工具、检索、原始材料、传感器。
2. 工作记忆与任务定向：context 预算、chunk、OODA Orient。
3. 世界模型与状态估计：控制论、Kalman/贝叶斯、证据边界。
4. 决策与执行控制：P10/P9/P8、OODA Decide/Act、routing。
5. 反馈与稳定性：测试、build、audit、Lyapunov 风格 V/Vdot。
6. 学习与进化：达尔文/模因/双环学习/skill steward。
7. 治理与安全：少数意见、模型名不是证据、secret gate、blast radius。
8. 资源与停止条件：边际效用、有限理性、通信预算、成本 envelope。

## Hard Acceptance Criteria

- 互补矩阵无缺失配对：`missing_pairs = 0`。
- 跨学科配对总表全部 A+：`below_a_plus = 0`。
- 所有 A+ 都是“理论 × Agent 能力 × 工具证据 × 本地大脑落地”的组合评级，不把模型共识当事实证据。
- 每轮自检必须使用本地大脑：`brainctl status/sync/reindex/search` + `local_brain_exhaustive_audit.py` + `agent_cos_selfcheck.py`。
- 不重写主层级；使用 semantic/control-plane overlay。
