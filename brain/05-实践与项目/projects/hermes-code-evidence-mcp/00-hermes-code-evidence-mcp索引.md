# Hermes Code Evidence MCP Fusion 索引

## 项目定位

长期项目：把 GitNexus 的 MCP/code-intelligence 治理原语融合进 Hermes 多模型思考，但只做 Hermes-native 方法论提取，不整体引入 GitNexus runtime。

核心目标：多模型不再只互相讨论，而是在代码变更、MCP/tool 变更、跨 repo/API 变更前后绑定同一组结构化证据：impact、context、contract、shape、staleness、detect_changes。
