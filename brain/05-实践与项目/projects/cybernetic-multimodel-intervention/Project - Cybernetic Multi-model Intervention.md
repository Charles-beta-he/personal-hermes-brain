# Project - Cybernetic Multi-model Intervention

## North star

把一阶控制论与二阶控制论转成多模型思考的可执行介入协议：

- 一阶：多模型作为外部控制器，介入 object task，产生假设、计划、风险，但必须由 tool evidence 验证。
- 二阶：多模型与 orchestrator 同时观察 observer/controller 本身，审计路由、skill、memory、验证规则、证据门是否漂移。

## Why now

现有笔记已经覆盖“一阶/二阶控制论”和“model agreement is not evidence”，但组合查询之前为空：`一阶控制论 二阶控制论 first-order cybernetics second-order cybernetics 多模型思考`。缺口不是理论，而是 operational intervention protocol。

## Scope

- P10 策略：定义一阶/二阶介入边界。
- P9 backlog：给出 P0/P1/P2 落地路线。
- Playbook：把多模型思考流程拆成 First-order gate + Second-order gate。
- Review：记录本轮多模型结果与 not_certified caveat。
- Atoms：沉淀可复用原则卡。
- Self-check：本地脚本验证 artifact、索引、结构审计。
