# 03 - 可靠性理论与浴盆曲线

## 核心概念

可靠性工程关注系统在给定时间内保持功能的概率。浴盆曲线描述故障率的三个阶段：

1. 早期故障：新系统/新流程尚未稳定。
2. 随机故障：稳定运行期的偶发问题。
3. 磨损故障：长期积累的老化、漂移和熵债。

## Agent 映射

| 阶段 | Hermes 风险 | 对策 |
|---|---|---|
| 早期故障 | 新 skill / 新脚本 / 新目录结构缺验证 | TDD、proof log、small slice |
| 随机故障 | provider 超时、CLI 偶发失败、搜索漏命中 | fallback、retry、bounded timeout |
| 磨损故障 | memory ghost、过期 skill、cron drift | steward、reindex、post-update healing |

## 设计启示

自进化不是只增加能力；也要降低长期故障率。每次新增结构都应有维护规则和审计入口。
