这个目录补齐“控制论基础”的理论底座。它不是 Hermes 运行日志，而是给后续 Agent 自进化、技能治理、多模型控制面、长期任务闭环提供可引用的理论支撑。

## 为什么需要这一层

之前本地大脑里已有 `99-hermes-notes/engineering-cybernetics/ch*.md` 的工程控制论章节镜像，也有 `03-理论与元认知/系统理论/Ashby-必要多样性定律.md`、`03-理论与元认知/系统理论/SecondOrder-二阶控制论.md` 等系统理论笔记；但 `03-理论与元认知/控制论基础/` 目录本身为空，导致：

- 其他笔记链接 `[[03-理论与元认知/控制论基础/01-反馈回路与稳定性]]` 时没有对应落点。
- 控制论核心概念没有统一入口。
- Agent 自进化中的“反馈、稳定性、观测、调节器、多样性、二阶观察”缺少基础层解释。

## 关键原则

1. 控制不是“强行执行”，而是“通过反馈减少目标偏差”。
2. 反馈没有稳定性设计会振荡；稳定性没有可观测性会失明。
3. 模型一致不是证据；证据是控制系统的观测输入。
4. 多模型、多工具、多 skill 是 Ashby 必要多样性在 Agent 系统中的实现。
5. Hermes 自进化必须是二阶控制：不只优化任务执行，也要审计自己的优化规则。
