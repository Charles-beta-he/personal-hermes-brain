# 02 - 大系统理论：分解与协调

## 核心概念

大系统无法靠单一控制器直接穷举所有状态，必须通过分解、层级、接口和协调机制降低复杂度。

## Agent 映射

| 大系统概念 | Hermes 映射 |
|---|---|
| 子系统分解 | skills、tools、cron、subagent、local brain layers |
| 接口 | task contract、frontmatter、JSON schema、proof log |
| 协调器 | P10/P9、router、多模型 arbiter |
| 局部自治 | 独立 worktree、子任务、cron job |
| 全局一致性 | sync/reindex/search、git commit、evolution log |

## 设计启示

本地大脑本身是大系统：理论、证据、任务、项目、技能、偏好和评审必须分层；否则所有内容混在一起会导致检索熵上升。
