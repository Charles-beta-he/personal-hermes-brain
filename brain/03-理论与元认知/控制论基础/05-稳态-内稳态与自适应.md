# 05 - 稳态、内稳态与自适应

## 核心概念

内稳态指系统在外界扰动下维持关键变量在可生存范围内。它不是静止，而是动态调节。

对于 Agent，关键变量不是体温或血糖，而是：

- 任务成功率
- 验证通过率
- 用户纠正频率
- cron/job 健康
- 模型/工具可用性
- 本地大脑可检索性
- 记忆幽灵率

## 自适应

自适应是当环境长期变化时，控制器自身参数或结构发生调整。

Agent 映射：

| 生物/控制概念 | Agent 映射 |
|---|---|
| 内稳态变量 | usage score、route pass rate、cron_bad、indexed_blocks |
| 传感器 | self-test、p10-health、brainctl status/search |
| 调节器 | self-improvement pipeline、skills patch、cron wrapper |
| 降级路径 | fallback model、script-first cron、bounded wrapper |
| 病理状态 | 空响应、ghost memory、技能泛滥、验证缺失 |

## 设计启示

1. 健康检查应该周期化，而不是问题爆发后手动跑。
2. 自适应改动必须有准入门；否则“优化”会变成随机游走。
3. 长期自进化应记录 V/Vdot 或等价健康趋势。
4. 稳态目标不是“永远不失败”，而是失败后能快速观测、定位、恢复。
