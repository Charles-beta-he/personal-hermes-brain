# Darwin：技能进化

## 核心命题

技能生态可以用演化论理解：变异产生候选方案，选择保留有效方案，遗传把有效模式固化为 skill/template/playbook。

## Agent 映射

| 演化概念 | Hermes 映射 |
|---|---|
| 变异 | 多模型方案、不同实现路线、模板改良 |
| 选择 | test/build/search/user correction |
| 遗传 | skill patch、模板、local brain atom |
| 适应度 | 使用频率 × 成功率 × 验证通过率 |
| 生态位 | devops/research/note-taking/UI 等任务域 |

## Evidence Boundary

- 来源支持什么：该卡仅记录理论概念、经典解释或本地大脑已引用的工程化映射。
- Hermes 映射边界：Agent/多模型/技能治理映射是工程类比与设计启发，不等同于原理论在数学或社会科学意义上的严格证明。
