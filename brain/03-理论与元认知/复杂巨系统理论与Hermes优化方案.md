## TOP 5 优化方向 (多模型共识)

### #1 系统级状态函数 V(x) + 复杂性仪表盘

**理论基础**: 维纳《控制论》反馈控制 + Lyapunov 稳定性理论 + Rosen 复杂系统可观测性

**问题**: 当前系统缺乏统一的"健康度"指标。各子系统独立自检，无全局状态函数。

**实施方案**:
1. 定义状态向量 x = [任务积压数, 失败率, 平均完成时间, 模型可用率, 冲突组饱和度, cron健康度]
2. 构造 V(x) = Σ wᵢ·fᵢ(xᵢ) 加权健康函数，V∈[0,1]
3. 当 V(x) < 0.5 时触发降级模式 (减少并行数、暂停进化任务)
4. 仪表盘实时展示 V(x) 及各分量

**预期影响**: 全局健康度可观测，异常早发现
**工作量**: medium

### #2 近可分解性重构 + 层次解耦 + 半透膜边界

**理论基础**: 西蒙《人工科学》近可分解性原理 + 维纳半透膜边界

**问题**: 子系统边界不清晰。brain orchestrator、envelope bus、kanban bridge、controller 之间有隐式耦合。

**实施方案**:
1. 按西蒙近可分解性原则重新划分子系统：
   - 强耦合内部: envelope_bus 内部状态机
   - 弱耦合接口: orchestrator↔controller 通过 JSON API
   - 半透膜: brain↔kanban 只允许单向信息流
2. 定义标准化接口协议 (JSON schema)
3. 添加边界违规检测 (跨边界写入告警)

**预期影响**: 降低认知成本，隔离故障传播
**工作量**: high

### #3 CAS 自组织调度 + 闭环自适应

**理论基础**: 霍兰《隐秩序》复杂适应系统 + Prigogine 耗散结构 + 多智能体强化学习

**问题**: 当前调度是中心化的规则驱动。动态 N 基于简单公式，不能从历史中学习。

**实施方案**:
1. 给每个冲突组分配"适应度"分数 (基于历史完成率、失败率)
2. 调度器根据适应度调整组优先级 (高适应度组获得更多并行资源)
3. 引入探索-利用平衡: 90% 按适应度调度, 10% 随机探索
4. 每轮 cycle 自动更新适应度 (闭环反馈)

**预期影响**: 调度质量随时间提升
**工作量**: medium

### #4 级联故障模型 + 不确定性量化

**理论基础**: 韦斯特《规模律》+ 贝叶斯推断 + Knight 不确定性

**问题**: 一个模型失败可能级联影响其他模型。缺乏证据强度评估。

**实施方案**:
1. 构建故障传播图: 模型A失败 → 对依赖A的任务的影响概率
2. 给每个 ratification 投票附加置信度 (0-1)
3. 当某模型连续失败 N 次，自动降级其投票权重
4. 不确定性传播: 上游不确定 → 下游决策需要更多佐证

**预期影响**: 防止级联故障，提高决策可靠性
**工作量**: medium

### #5 涌现观测 + 受控涌现

**理论基础**: 霍兰《隐秩序》涌现理论 + Santa Fe CAS + 反脆弱实验

**问题**: 多模型共识可能产生涌现行为 (意外的高质量结论或意外的系统性偏差)。当前无观测机制。

**实施方案**:
1. 记录每次多模型投票的分歧模式 (哪个模型经常与多数不同)
2. 检测系统性偏差: 如果 3/4 模型总是同意第 4 个，可能是群体思维
3. 定期注入"对抗性提案"测试系统反应 (反脆弱实验)
4. 设置复杂度预算: 子系统数量上限，防止过度膨胀

**预期影响**: 发现隐藏模式，防止群体思维
**工作量**: low
