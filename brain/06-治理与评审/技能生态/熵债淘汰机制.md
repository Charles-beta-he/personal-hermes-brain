# 熵债淘汰机制

> 基于 Prigogine 耗散结构理论
> 联系：[[03-理论与元认知/系统理论/Prigogine-耗散结构|Prigogine]] ｜ [[06-治理与评审/技能生态/skill-steward角色定义|Steward]]

## 核心公式

```
ΔS_skills = +1（创建） - k × n（淘汰）
稳态条件: ΔS_skills ≈ 0
其中 k ≥ 1（一个创建至少对应一个淘汰）
```

## 熵债票

每个创建操作产生一张熵债票：

| 创建类型 | 熵值 | 偿还期限 | 偿还方式 |
|---------|------|---------|---------|
| 新的完整 skill | 3 | 48 小时 | 废弃 1 个旧 skill + 修复 2 个断裂引用 |
| 轻量 skill (< 1KB) | 1 | 24 小时 | 废弃 1 个旧 skill |
| 仅 reference 文件 | 0.5 | 无期限 | 无需偿还 |
| 更新已有 skill | 0 | — | 不产生熵债 |

## steward cron 的淘汰策略

### 每日扫描（凌晨 2:00）
```python
# 1. 标记僵尸
if skill.age_days > 90 and not skill.has_tests and not skill.has_changelog:
    skill.state = DEPRECATED

# 2. 执行过期
if skill.state == DEPRECATED and skill.age_days > 150:
    skill.state = ARCHIVED  # 从活跃集移除

# 3. 最终删除
if skill.state == ARCHIVED and skill.age_days > 240:
    skill.delete()  # 物理删除
```

### 梯度时间线

| 时间   | 年龄    | 制裁等级                        |
| ---- | ----- | --------------------------- |
| 创建   | 0 天   | BETA                        |
| 首次审查 | 30 天  | 如无使用 → DEPRECATED           |
| 淘汰临界 | 90 天  | 如无测试+changelog → DEPRECATED |
| 归档   | 150 天 | ARCHIVED（从列表消失）             |
| 删除   | 240 天 | DELETED（物理清理）               |
