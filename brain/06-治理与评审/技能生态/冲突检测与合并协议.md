## 合并协议

### 情形 A：同一方法论 + 多副本

```
合并策略：
  - 选择 1 个 canonical 位置（通常是根层）
  - 将其他副本替换为 SKILL.md 中的 alias 引用：
    ---
    name: pua
    alias: true
    canonical: ~/.hermes/skills/pua/SKILL.md
    ---
  - 运行 skill_view('pua/skills/pua') 时自动重定向
```

### 情形 B：同一主题 + 不同作者

```
合并策略：
  - 在 canonical 的 SKILL.md 中增加 variants 节
  - variants 列出各平台的适配差异
  - 公共部分合并，差异部分保留
```

### 情形 C：同名 + 不同功能

```
合并策略：
  - 重命名以消除歧义
  - post-deploy-verification → post-deploy-verification-standard
    或保留根层，software-development 版改为别名
```

## 自动化冲突检测

已集成在 `skill-steward.py` 中，每次审计自动输出：

```bash
python3 ~/.hermes/scripts/skill-steward.py --report
# 输出中包含 "同名冲突: N" 项
```
