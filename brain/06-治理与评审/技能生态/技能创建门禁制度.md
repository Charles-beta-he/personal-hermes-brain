## 创建前 Checklist（必须逐项确认）

在调用 `skill_manage('create')` 之前，必须确认以下全部：

```
[ ] 1. 在全库搜索过 — 是否已有覆盖此场景的技能？
[ ] 2. 无法通过扩展现有技能实现？
[ ] 3. 已准备好至少 2 个 test-prompts 用例？
[ ] 4. 已有 CHANGELOG 首条记录？
[ ] 5. 当前 skill 总数是否 < 200？
[ ] 6. 是否标记了一个废弃技能作为熵债偿还？
```

**缺少任意一项 → 不创建。**

## 生命周期状态机

```
         ┌──────────────────────────────────┐
         │                                  │
         ↓                                  │
    ┌─────────┐  30天无使用    ┌────────────┐│
    │  BETA   │ ───────────→  │ DEPRECATED ││
    └─────────┘               └────────────┘│
         │                        │         │
         │ 有测试+changelog        │ 60天无操作 │
         ↓                        ↓         │
    ┌─────────┐               ┌────────────┐│
    │ ACTIVE  │               │  ARCHIVED  │─┘
    └─────────┘               └────────────┘
                                    │
                                    │ 90天无恢复
                                    ↓
                               ┌────────────┐
                               │  DELETED   │
                               └────────────┘
```

## 梯度制裁（Ostrom 原则 5）

| 阶段         | 行为                   | 效果             |
| ---------- | -------------------- | -------------- |
| BETA       | 正常可用，满30天自动审查        | 活跃集中排在末位       |
| DEPRECATED | 在 skill_view 中显示⚠️警告 | 不被活跃集收录        |
| ARCHIVED   | 不出现在技能列表，需手动搜索       | 完全从 agent 视角隐藏 |
| DELETED    | 物理删除                 | 永久消失           |

## 创建流程（带 Havel 摩擦）

```python
# 第 1 步：搜索现有库
search_results = search_files(pattern="*"+keyword+"*", target="content", path="~/.hermes/skills")
if len(search_results["matches"]) > 0:
    # 应优先扩展现有技能，而非创建新技能
    print("⚠️ 已有相关技能，建议扩展而非创建")

# 第 2 步：检查总数
total = len(list(Path("~/.hermes/skills").rglob("SKILL.md")))
if total >= 200:
    raise SystemError("技能总数超限，必须先 ARCHIVE 至少 N 个")

# 第 3 步：熵债要求
# 必须同时标记一个 DEPRECATED 技能
if not has_entropy_debt_assigned():
    raise SystemError("请先标记一个废弃技能作为熵债")
```
