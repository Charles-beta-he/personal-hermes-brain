# Hermes Core Routing Policy v0.1.0

Route to hermes-core when the task touches:
- Hermes runtime source, provider/model routing, tools, memory, taskpool, cron, gateway, conductor, or self-evolution.
- `hermes-agent-private` topology, upstream sync, overlay registry, post-update guard.
- `personal-hermes-brain` sanitized backup scripts/skills/project-profiles.
- Taskpool event hooks and multi-model certification routes.

Escalate to real multi-model certification when:
- a change modifies hook eligibility, auto-close behavior, certification semantics, or permission boundaries;
- a patch can affect runtime upgrade safety or brain backup integrity;
- architectural acceptance/retirement of an overlay is unclear.

Use deterministic local checks before invoking expensive models.
