# Stability Margin — 稳定裕度与容错指标

> ch03 稳定性: 定义 Agent 容错指标——模糊输入/错误反馈下的成功率

## 容错维度

| 维度 | 定义 | 测试方法 | 目标值 |
|------|------|---------|--------|
| **输入容错** | 模糊/不完整需求下的正确理解率 | 5 种噪音输入测试 | ≥ 80% |
| **反馈容错** | 错误/矛盾反馈下的正确响应率 | 注入错误验证结果 | ≥ 70% |
| **环境容错** | 缺失依赖/权限下的优雅降级率 | 模拟缺失工具 | ≥ 60% |
| **时间容错** | 超时/中断后的恢复完成率 | 模拟中断后恢复 | ≥ 90% |
| **并发容错** | 多任务并行时的无冲突率 | 5 个并行 sub-agent | ≥ 85% |

## 噪音输入测试集

### 测试 1: 模糊需求
```
输入: "帮我改改这个"
期望: Agent 追问"改什么？"或基于上下文推断最可能意图
```

### 测试 2: 矛盾约束
```
输入: "用最少代码实现最复杂功能，但要最高性能"
期望: Agent 指出矛盾，要求优先级排序
```

### 测试 3: 缺失上下文
```
输入: "修复上次那个问题"
（session_search 无结果）
期望: Agent 承认缺失上下文，询问具体信息
```

### 测试 4: 错误技术栈
```
输入: "用 React 实现 Vue 的 computed"
期望: Agent 解释差异，提供等效方案
```

### 测试 5: 超大任务
```
输入: "重构整个互联网"
期望: Agent 拒绝或分解为可管理子任务
```

## 稳定裕度计算

```
stability_margin = min(输入容错, 反馈容错, 环境容错, 时间容错, 并发容错)

健康状态:
  margin ≥ 0.80: 稳定（绿色）
  0.60 ≤ margin < 0.80: 临界（黄色）→ 增加验证频率
  margin < 0.60: 不稳定（红色）→ 停止执行，进行稳定性修复
```

## 与现有体系集成

- 健康度 V 中的 "任务成功率" 使用稳定裕度加权:
  `adjusted_success_rate = raw_success_rate × stability_margin`
- 稳定裕度 < 0.60 → 触发 P10 战略 review
- 每季度运行一次完整噪音测试集
