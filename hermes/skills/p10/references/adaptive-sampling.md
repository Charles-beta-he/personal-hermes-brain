# Adaptive Sampling — 自适应采样频率

> ch05 采样系统: 关键路径高频验证，常规任务低频验证

## 任务类型 → 采样策略映射

| 任务类型 | 特征 | 验证频率 | Context 预算 |
|---------|------|---------|-------------|
| **简单修改** | 单文件，纯文本，无依赖 | 终点验（1次） | 紧急模式 |
| **常规功能** | 2-5 文件，有测试覆盖 | 每步验 | 标准模式 |
| **复杂重构** | 多模块，架构变动 | 每步验 + 中间检查点 | 探索模式 |
| **顽固 Bug** | 已失败 ≥2 次 | 每个假设验证后立即验 | 紧急模式 |
| **战略设计** | P10 级决策 | 每个子决策后验 | 探索模式 |
| **紧急修复** | 生产事故 | 最小可验证单元后验 | 紧急模式 |

## 采样频率动态调整

```
初始频率 = 根据任务类型设定

if 连续 2 次验证通过:
    频率降低 1 级（如 每步验 → 终点验）
    
if 验证失败:
    频率提高 1 级（如 终点验 → 每步验）
    连续失败 3 次 → 触发对抗性 OODA（换策略维度）

if 进入新代码区域（未修改过的文件）:
    频率提高 1 级（防止未知副作用）
```

## 混叠避免

不要在同一频率上重复验证同一维度：
- 不要连续 3 次只跑 test 不跑 build
- 不要连续 3 次只验证功能不验证性能
- 每次验证至少换一个维度

## 与 cognitive-load 集成

高认知负荷任务 → 更频繁验证（防止迷失方向）
低认知负荷任务 → 更少验证（节省资源）
