# Time-Scale Separation — 分层决策频率

> ch14 分散控制: P10慢/P9中/P8快；最小必要信息共享

## 决策频率定义

| 层级 | 角色 | 决策周期 | 信息模式 | 输出物 |
|------|------|---------|---------|--------|
| **P10 (战略)** | CTO | 每季度 review | 全局状态 + 趋势 | reference-model.md 更新 |
| **P9 (管理)** | Tech Lead | 每周 review | 项目进度 + 阻塞 | task prompt 更新 |
| **P8 (执行)** | Engineer | 每日/每次任务 | 具体代码 + 验证 | 代码 + 测试 |
| **Loop (迭代)** | Auto | 每轮 (分钟级) | 当前状态 + 偏差 | loop-report |

## 信息共享规则

```
P10 → P9: 战略方向、约束条件、资源分配
P9 → P10: 进度摘要、风险告警、资源需求

P9 → P8: 任务描述、验收标准、依赖关系
P8 → P9: 执行结果、阻塞原因、时间估算

P8 → Loop: 具体目标、验证标准
Loop → P8: 完成状态、验证结果、偏差报告

禁止:
  P10 直接给 P8 发指令（绕过 P9）
  Loop 向 P10 汇报（信息过载）
```

## 触发条件

| 事件 | 触发层级 | 响应时间 |
|------|---------|---------|
| V̇ < -0.05 连续 2 次 | P10 | 24 小时内 |
| 同问题复发 3 次 | P9 | 立即（切换策略） |
| Build 失败 | P8 | 立即（修复） |
| 验证失败 | Loop | 立即（下一轮修复） |
| 新类型任务首次出现 | P10 | 下次 review |
| 用户重大纠正 | P9 | 下次 task prompt 更新 |

## 与 Cronjob 集成

```
每 4 小时:  Loop 自扫描
每日 00:00: P8 健康度检查
每周一 09:00: P9 进度 review
每季度:     P10 战略 review
```
