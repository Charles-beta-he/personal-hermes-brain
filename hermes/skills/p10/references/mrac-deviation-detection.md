# MRAC Deviation Detection — 模型参考自适应控制

> ch10 MRAC: 实际工作流 vs 参考模型 → 偏差检测自动告警

## 偏差检测机制

### 检测维度

| 维度 | 参考模型值 | 实际值来源 | 告警阈值 |
|------|-----------|-----------|---------|
| 阶段完整性 | [0]-[9] 全部执行 | session 记录 | 任何阶段缺失 |
| 验证频率 | 按任务类型设定 | todo 验证状态 | < 参考频率 |
| 单轮耗时 | 参考模型耗时 | loop-report 计时 | > 200% |
| 代码质量 | UIMax A+ | browser_vision audit | < A |
| 迭代次数 | 按任务类型上限 | 实际轮次 | > 上限 |
| 用户纠正 | 0 次/轮 | session 记录 | ≥ 1 次 |

### 偏差计算

```
deviation_score = Σ(|实际_i - 参考_i| / 参考_i × 权重_i)

权重分配:
  阶段完整性: 0.30
  验证频率:   0.20
  单轮耗时:   0.15
  代码质量:   0.15
  迭代次数:   0.10
  用户纠正:   0.10

偏差等级:
  deviation < 0.10: 正常（绿色）
  0.10 ≤ deviation < 0.30: 轻微偏差（黄色）
  0.30 ≤ deviation < 0.50: 显著偏差（橙色）
  deviation ≥ 0.50: 严重偏差（红色）→ 触发复盘
```

### 自适应响应

| 偏差等级 | 自动响应 |
|---------|---------|
| 绿色 | 继续执行 |
| 黄色 | 输出警告，建议关注 |
| 橙色 | 输出警告，自动调整采样频率（提高1级） |
| 红色 | 暂停执行，输出偏差分析报告，建议用户介入 |

## 与现有体系集成

- 健康度 V 中的 "迭代效率" 使用 MRAC 偏差加权计算
- 偏差橙色以上 → bayesian-agent 对当前 skill beta + 1
- 偏差红色 → 触发 incident-response skill
