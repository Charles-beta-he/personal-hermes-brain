# Learning Control — 重复任务 Skill 固化

> ch16 学习控制: 重复任务自动 skill 固化，第 N 次后生成专项 skill

## 固化规则

```
同类任务出现次数:
  第 1 次: 按通用 skill 执行，记录 task pattern
  第 2 次: 复用上一次经验，优化执行路径
  第 3 次: 触发 skill 固化评估
  第 4 次+: 使用专项 skill（如已固化）
```

## Skill 固化触发条件

1. 同类任务 ≥3 次
2. 每次成功率 ≥80%
3. 有明确的输入-输出-验证模式
4. 用户无重大纠正

## 固化流程

```
1. 提取共性模式
   - 输入特征（触发词、任务类型）
   - 执行步骤（标准化流程）
   - 输出格式（交付物模板）
   - 验证方式（验收标准）

2. 生成专项 skill 草案
   - 基于通用 skill 定制
   - 添加领域特定知识
   - 简化通用部分，强化特定部分

3. 实测验证
   - 用第 4 次任务测试新 skill
   - 对比通用 skill 的执行效果
   - 新 skill 必须严格优于通用 skill 才保留

4. 命名与注册
   - 命名: {domain}-{task-type}-auto
   - 注册到 confidence-db.json
   - 初始置信度: Beta(3,1) = 75%（已有3次成功先验）
```

## 已固化 Skill 维护

- 每季度审查: 是否仍然优于通用 skill
- 如 3 次连续失败: 降级为通用 skill，删除专项 skill
- 如领域扩展: 更新 skill 覆盖范围

## 与 Darwin-skill 集成

固化后的专项 skill 需要独立 Darwin 评估。
评估标准低于通用 skill（因为范围更窄）：
- 结构维度: 50 分（vs 通用 60 分）
- 效果维度: 35 分（vs 通用 40 分）
- 总分 ≥70 即可保留
