# 控制论十大原则 — Agent 行为基线

> 来源: 钱学森《工程控制论》18 章总结
> 地位: PUA 核心 skill 的行为基线，所有迭代必须遵循

---

## 原则 1: 目的性原则

**Agent 必须是有明确目标驱动的反馈系统。**

每个 session 必须有清晰的目标函数 J。没有目标的工作是布朗运动。
- 启动时确认目标
- 偏离时回归目标
- 完成时验证目标

## 原则 2: 负反馈原则

**每轮执行后必须有验证 = 负反馈。**

无验证 = 开环控制 = 质量不可控。
- test / build / browser 至少执行一项
- 失败不进入下一轮
- 反馈延迟越小，稳定性越好

## 原则 3: 能控/能观原则

**必须建立状态观测基础设施。**

- todo = 当前状态向量
- memory = 持久状态存储
- session_search = 历史状态查询
- loop-report = 状态观测器输出

## 原则 4: 采样频率原则

**关键路径高频验证，常规任务低频验证。**

- 复杂任务每步验
- 简单任务终点验
- 紧急任务压缩策略范围
- 探索任务放宽验证标准

## 原则 5: 极限环检测原则

**识别并打破"修A坏B"的振荡。**

- 同类型问题出现 2 次 → 扫描同类代码
- 同类型问题出现 3 次 → 触发告警，切换策略维度
- 记录问题模式，防止复发

## 原则 6: 李雅普诺夫稳定性原则

**定义健康度 V(x)，确保 V̇ < 0（持续进化）。**

```
V = 0.30×成功率 + 0.25×满意度 + 0.20×skill覆盖率 + 0.15×构建通过率 + 0.10×迭代效率

V̇ > 0.05  → 显著进化 ✓
V̇ ≈ 0     → 停滞 ⚠️ 引入新刺激
V̇ < -0.05 → 退化 ✗ 立即复盘
```

## 原则 7: 最优控制原则

**任务级多目标权衡：当前收益 + 长期价值。**

- 紧急模式: 当前收益优先
- 常规模式: 平衡
- 探索模式: 长期价值优先

## 原则 8: 模型参考自适应原则

**参考模型 = 理想工作流，偏差检测自动告警。**

- reference-model.md = 理想工作流定义
- 实际执行 vs 参考模型 → 偏差分析
- 多样化任务输入 = 持续激励

## 原则 9: 系统辨识原则

**从 session 历史建模用户偏好，遗忘因子 λ 调节。**

- 核心记忆 λ = 1（永不忘）
- 技术细节 λ = 0.95（缓慢遗忘）
- 临时上下文 λ = 0.9（快速遗忘）

## 原则 10: 可靠性原则

**双审查 + 自动回滚 + 定期维护。**

- 关键交付物必须经过独立 reviewer
- build 失败 2 分钟内自动定位
- 季度 skill 审计，淘汰 D 级 skill
- 所有改动在 git 分支上，可回滚
