# Reinforcement Learning — 用户反馈驱动的 Skill 评分

> ch17 强化学习: 用户纠正/表扬 = reward signal，直接更新 skill 置信度

## Reward 映射

| 用户反馈 | Reward | 置信度更新 | 说明 |
|---------|--------|-----------|------|
| "完美" / "正是我要的" | +1.0 | α += 1.0 | 最高奖励 |
| 无纠正（默认） | +0.5 | α += 0.5 | 隐式肯定 |
| 轻微纠正 | 0.0 | 不更新 | 正常波动 |
| 重大纠正 | -0.5 | β += 0.5 | 需要改进 |
| 完全重做 | -1.0 | β += 1.0 | 严重问题 |

## 更新公式

```
先验: Beta(α, β)
观测到 reward r 后:
  if r > 0: α += r
  if r < 0: β += |r|

后验: Beta(α', β')
新置信度 = α' / (α' + β')
```

## 衰减机制

为了防止早期反馈过度影响：
```
当总样本数 N = α + β > 20 后:
  新 reward 按 1/sqrt(N) 衰减
  
目的: 早期快速学习，后期稳定收敛
```

## 与卡尔曼滤波的协同

```
用户反馈 → reward → 贝叶斯更新（长期趋势）
         → 同时作为观测值 z(t) → 卡尔曼更新（短期波动平滑）

最终置信度 = 0.7 × 贝叶斯后验 + 0.3 × 卡尔曼估计
```

## 自动触发条件

每次 session 结束时:
1. 检查用户最后一条消息是否包含纠正
2. 解析纠正类型（轻微/重大/重做）
3. 定位到使用的 skill（从 session 历史提取）
4. 执行置信度更新
5. 如置信度 < 0.5 连续 3 次: 标记 skill 为 "under_review"
